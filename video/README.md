# Praetor Demo Video

Remotion product walkthrough styled after the Praetor dashboard: dark green command-center UI, neon mint system signals, gold actions, monospace telemetry, and HUD-style panels.

## Run

```bash
cd video
npm install
npm run start
```

Open the `PraetorDemo` composition in Remotion Studio to preview it.

## Render

```bash
npm run render
```

The 1920x1080 MP4 is written to `video/out/praetor-demo.mp4`.
